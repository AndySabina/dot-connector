# 0.1.12 experimental

Adds an explicitly enabled, owned synthetic tmux session, bounded MCP snapshot
transport and human-priority input arbitration. The default plugin remains
diagnostic-only. No live terminal adoption, cloud delivery or VT streaming claim.

Adds one per-user configuration schema shared by CLI and local JavaScript API,
redacted diagnostics, actionable noninteractive failures and revision-checked
atomic writes. No credential is required or accepted. ChatGPT sign-in remains
with the host. An isolated diagnostic installer avoids Windows helper preparation.

See [README](../README.md), [configuration](PRIVATE-CONFIG.md) and
[bridge contract](TMUX-BRIDGE.md). Install/update uses the existing numeric release,
tag, manifest and SHA-256 verification flow; keep experimental registration
separate from the original plugin.
